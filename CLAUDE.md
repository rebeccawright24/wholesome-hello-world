# Wholesome Hello World

## About this project
- My practice project for learning the basics: a tiny Hello World page. It's fine to experiment and break things here.
- A plain static website: HTML, CSS and a little JavaScript. No frameworks, no npm, no build step.
- Live at https://<username>.github.io/wholesome-hello-world/. Every push to main publishes it via .github/workflows/deploy.yml.

## How to work with me
- I'm Rebecca, a beginner, and I'm vibe coding: I describe what I want and you write the code.
- Explain things in plain words and keep it short. Teach the idea, not the code line by line.
- Before changing files, tell me your plan in a sentence or two.
- Work in small steps. After each one, tell me exactly what to look at in Chrome.
- Ask before anything that costs money, deletes files or makes something public.

## Rules for the code
- index.html is the home page; each extra page is its own .html file. style.css is how it looks; script.js is for anything interactive.
- Use relative links and paths (about.html, images/logo.svg), never ones starting with /, because the site lives in a subfolder on GitHub Pages.
- Every page should look good at iPhone size as well as on the Mac.
- Don't add libraries, frameworks or new tools without asking me first.

## Saving and publishing
- Commit after each change that works, with a short message saying what changed.
- Before pushing, tell me in plain words what's about to go live.
- Never force-push, rewrite history or delete branches.
- If something breaks, help me go back to the last commit that worked.

## Things I've asked you to remember
- Always tell me what to look at in Chrome.
- Show me one task at a time, and only show the next one when I've finished it.
